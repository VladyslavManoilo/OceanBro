# Retro Game Covers (Simplified OpenVGDB)

This repository provides a **clean, lightweight, and easy-to-use** version of the OpenVGDB database — specifically focused on game cover art (box, front, back, etc.) for retro consoles and classic gaming systems.

### Purpose
The main goal of this project is to make it simple and fast to:
- Download high-quality cover artwork
- Use in ROM management tools, frontends (RetroArch, LaunchBox, EmulationStation, etc.)
- Browse or integrate into personal collections

### Source
This is a **simplified & cleaned-up derivative** of the excellent [OpenVGDB project](https://github.com/OpenVGDB/OpenVGDB).

Original OpenVGDB repository:  
→ https://github.com/OpenVGDB/OpenVGDB
